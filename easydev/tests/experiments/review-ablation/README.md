# 独立审查四臂消融协议

本目录保存独立审查对照消融实验协议，用于评估独立审查、异构模型与分级审查的实际收益。不包含实验结果，不进 CI。

## 四臂设置

| 臂 | 开发角色 | 独立审查角色 | 验证目标 |
| --- | --- | --- | --- |
| A | 基准模型 | 无 | 仅实施与自查的基础基线 |
| B | 基准模型 | 同模型跨实例 | 独立审查本身的净收益 |
| C | 基准模型 | 同强度异构模型 | 异构视角带来的额外收益 |
| D | 轻量/较低成本模型 | 强推理审查模型 | 成本非对称路由的有效性 |

B 与 C 仅改变审查模型的异构性；C 与 D 仅改变开发与审查的能力组合，严禁混淆变量。

## 任务与预算

- 任务须同时覆盖局部低风险、公共契约变更、多调用方适配、高风险鉴权/数据流及隐蔽缺陷。
- 任务冻结代码快照、原始输入、模型与推理深度、工具沙箱与最大步数。
- 采用执行者不可见的独立验收，各臂结果按任务配对评估。
- 先行小样本功效预估后冻结任务集，不得根据结果中途增删用例。

## 记录指标

- **质量**：隐藏验收通过率、回归率、确认缺陷严重度分级、审查漏检与误报。
- **成本**：主代理与各子代理实际 token 消耗及 API 费用（分列记录）。
- **效率**：墙钟耗时、正式审查轮数、返工次数与阻塞时长。
- **人工**：必要人工干预次数与复核时长。

## 准入门槛

仅当高风险任务独立验收不下降、负向伪修复召回达标，且总成本、有效成本或耗时至少一项具备显著收益时，方可考虑纳入默认配置。
