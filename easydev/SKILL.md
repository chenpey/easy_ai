# easydev

主代理默认唯一写入者，委派见 [full 编排](references/workflow.md#full-编排)；子代理直达 [roles.md](references/roles.md) 的开发、审查与设计角色。

## 入口与任务分流

默认 auto。仅要 design/plan/debug/review/audit/demo 只交产物，只读路径不改代码、不跑全量测试、构建与全仓检查（`demo` 例外：仅写 `throwaway` 实验代码，不动业务代码）；实现自问：≥2 独立调用方？改共享契约且有未改使用方？无改前检查拦回归？用户是否要求独立审查？任一成立先读 workflow。

| 路径 | 条件与动作 |
| --- | --- |
| quick | 局部明确低风险且无第二视角信号：实施、验证、自查 |
| normal | 影响有界、有第二视角信号、非 full：独立定向审查，至多一次局部 P2 复审，无账本 |
| full | 高风险、重大契约/数据影响、关键影响调查仍不明或用户要闭环：按门控设计、独立审查、有限修复 |
| gate | 外部传入设计：先审设计无分歧再开发自验，跳过内部 `r/5`；高风险走 full（[workflow](references/workflow.md#gate-模式)） |

高风险边界（鉴权/支付/敏感数据/并发/破坏性操作/密码学/CI/供应链/生产日志等）读 [流程规则](references/workflow.md#高风险边界)。

## 开始工作

读约定、授权、Git 基线（提交与首次原内容，不含测试结果）、目标、调用方与测试；**改前不跑既有测试/构建摸底**（新写复现/红测与无 CI/旧记录的[纯重构](references/engineering.md#测试硬约束与选择)单次对照除外），改后失败先区分既有缺陷与新回归；仓库约定优先，不放宽安全/授权底线。一句话说明依据；保护用户改动，高代价歧义 [选项式澄清](references/design.md#选项式澄清)。

## quick 执行核心

quick 默认只读本页；例外必读：性能比较或收益声明读 [性能](references/engineering.md#测试硬约束与选择)，测试依赖未知外部能力读 [验证调度](references/engineering.md#验证调度与证据)；均不因此升级 full。

1. 复用已有实现与平台能力，最小改动并同步调用方、契约与文档。单次内联，≥2 处复用才提取；不加未被要求的类、接口、配置、参数、wrapper。只在边界防错，不减安全、错误处理与清理；不手改生成产物，改源头后重生；不用 `any`、空 catch 逃生舱写法。
2. 先核覆盖，仅为核心与关键失败缺口补端到端测试；不写单测，不用 mock 隔离内部。期望取需求/独立来源，新功能/Bug 记红绿证据，重构验行为保持。
3. 用项目脚本验证；独立无冲突项并行，同一工作区上同套或范围重叠的测试/构建在跑或已通过未失效时不重跑（隔离工作树分片与性能对比多次采样不限）。阻塞设硬超时；交代码前跑完整检查，纯文档免跑。
4. 修复尝试：同根因跨阶段限三次有新证据的候选修复（调查/环境不计），按根因或症状识别，换实例或编号不重置；三次仍失败即停。
5. 交付前自查冗余并等价简化；核对调用方、证据与风险，新影响重判。报改动、验证、未独立审查及限制，禁虚报通过；quick 计量仅在用户要求时提供（尝试次数与验证耗时）。

## 全程约束

- 授权跨阶段有效；提交、推送、发布、部署及对外消息须用户授权。
- 仅主代理控流程，其他技能不另开闭环。
- 并行分片先读 workflow：内容自判 1–6 片，用户指定优先；normal 单写，full 并写须满足独立性与隔离门槛，串行包装不得称并行。
- 除 quick/gate/无委派只读路径外，开工先按 environment 核实角色配置；未核实不得假定 inherit 自任设计或写入，分派以核实值为准。
- 区分自查、独立审查与受阻；无委派能力时暂停报受阻，经授权交审查包，不虚称 full 完成。
- 发现、预算与停止条件禁靠改名绕过。
