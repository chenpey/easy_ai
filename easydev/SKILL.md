# easydev

子代理按交接履职，读 [开发角色](references/roles.md#开发角色) 或 [审查角色](references/roles.md#审查角色)；不分流、分派、重置预算或宣布完成。

## 入口与任务分流

默认 auto，先确认交付类型。仅要 design / plan / debug 定位 / review / audit / spike 时只交付对应产物；实现才按实际影响选档，先自问：是否 ≥2 独立调用方依赖、是否改共享契约且有未改使用方、是否没有改前已有检查能拦住回归；任一成立先读 workflow 再定档。

| 路径 | 条件与动作 |
| --- | --- |
| quick | 局部、明确、低风险：实施、验证、自查 |
| normal | 影响有界、具第二视角信号且无 full 条件：独立定向审查与至多一次局部 P2 复审，无 full 账本 |
| full | 高风险、重大契约/数据影响、具体关键影响调查后仍不明，或用户要求闭环：设计按门控，独立审查与有限修复 |

涉及鉴权、支付、敏感数据、并发与破坏性数据操作、密码学与随机数、CI/构建/IaC/部署权限、依赖与供应链、生产日志与遥测等高风险边界一律读 [流程规则](references/workflow.md#分流判定)。normal 是实现路径非聊天长度档；风险疑点或路径变化读流程规则；文件数与关键词不单独定档。

## 开始工作

读约定、目标、授权、Git 状态与基线；改前读目标、直接调用方及测试。一句话说明路径依据。保护用户改动，按授权推进，高代价歧义先澄清。

## quick 执行核心

普通 quick 只需本页。

1. 优先复用已有实现与平台能力，做最小完整改动，同步受影响调用方、契约和说明。单次使用逻辑默认内联，≥2 处真实复用才提取；保持原生数据形态，不加需求外的抽象、包装、转换与配置。只在边界防错，不削减必要安全、错误处理与资源清理。
2. 先核对覆盖，只为核心路径与关键失败缺口补用户视角端到端测试；不写单测，不用 mock 隔离内部，不为覆盖率堆用例。期望值来自需求或独立来源，新功能与 Bug 记原因正确的红绿证据，重构验行为保持。
3. 用项目脚本验证；独立无冲突检查批量并行，依赖项串行，收齐每项退出状态。阻塞命令有硬超时；只在新改动、失败或未决疑点使证据失效时重跑；交付前跑完整检查。
4. 修复尝试遵循 [尝试预算](references/workflow.md#尝试预算)；失败先取证，三次仍失败即停。
5. 交付前自查可删冗余及更直接、易读的等价实现；核对调用方、验证证据与风险边界，新影响按规则重判。报告改动、验证、未做独立审查及实质限制，不称未执行通过；quick 计量仅在用户要求时提供。

## 按需加载

只读当前职责所需模块，专项模块按其触发条件使用。

| 场景 | 模块 |
| --- | --- |
| normal、full 编排、风险分流、预算 | [workflow](references/workflow.md)；[独立设计环节门控](references/design.md#启用门控) |
| 实现、代码质量、排障、重构、验证 | [engineering](references/engineering.md) |
| 澄清、计划、探针、多方案评审 | [design](references/design.md) |

| 模型配置、宿主适配、基线快照、工作树 | [environment](references/environment.md) |

## 全程约束

授权跨阶段有效；提交、推送、发布、部署及对外消息须用户授权。仅主代理控流程，其他技能不另开闭环。区分自查、独立审查与能力受阻；无子代理按 environment 交付审查包，不虚称 full 完成。发现、预算与停止条件禁靠改名绕过。
