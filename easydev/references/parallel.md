# 并行执行规程

## 并行执行

按内容判断并行，不以串并行对照评测作为启用前置。内容自判 1–6 片，用户指定片数优先；1 片即串行，默认不追求用满。同批活跃代理片（含提前审查）合计最多 6 片，不嵌套倍增。用户指定须为整数 1–6；指定 0、7 等越界或非整数时不启动该批分派，说明范围并等待改值。合法指定仍受安全门槛、独立片数与宿主额度限制；不能满足时报告冲突并采用可行的较少片数或串行，不为凑数拆片。判不准、无并行能力或被限流时串行，不算降级。

并行写入仅限 full；normal 保持单写。独立性与隔离条件全部成立才可并行，否则串行。**独立片**须同时满足：每片唯一写入者，写集互不相交；不依赖其他片尚未完成的结果；共享契约已冻结，各片可独立验证；单片工作量须大于调度开销。交接列写集、读取及验证依赖、工作区和资源，并简记判断依据；任一写集会改变其他片验证前提时串行。锁文件、生成物、迁移序号、公共配置等共享写点由主代理协调当前获授权写入者在拆分前或集成时串行处理；无法拆开依赖则冲突组串行。

高风险边界默认串行（鉴权、支付、敏感数据、迁移、发布权限等）；仅用户明确要求该高风险工作并行、上述独立性与下述隔离条件全部满足且每片可独立验证和恢复时例外。指定片数不等于高风险并行授权。账本记录高风险并行理由、用户授权来源、风险、隔离与恢复方式；不放宽 full、设计门控、独立审查或操作授权。

1. **只读并行**：调查、分片审查与证据核对无依赖且工作量大于调度开销时，按内容或用户指定取 1–6 片；同一冻结快照合计一轮。normal 可分派多个审查实例，主代理核对合并覆盖完整任务 diff 与调用链，仍计一次。
2. **审查流水线**（full）：片及其验证依赖冻结、验证后可提前送审，占 `r`；其他写入者仅继续不影响该快照的工作。写集、调用方、共享契约或验证依赖变化使相关证据失效，重审另占轮次。增量余量耗尽时停止可选流水线，收齐改动后按审查时机判定是否终审；必须先审的高风险契约未通过时不得施工其下游，余量不足则报未完成。
3. **隔离与验证**：需运行构建或测试的并行写入须用独立工作树，按 [工作区隔离](environment.md#工作区隔离与分支收尾) 核对同一任务基线（含已保护的相关未提交及未跟踪改动）并返回分片改动；端口、数据库、测试数据与输出目录须隔离。仅纯文档或可证明无构建、验证干扰时共享工作区；无法隔离则串行。主代理协调各批验证及最终整仓验证期间所有相关写入者停写，收齐停写确认后验证；验证失败或未验证片不得作为完成片集成。分片验证不替代最终完整检查；完成集成与完整检查后冻结完整任务 diff，按审查时机判定是否终审。
4. **集成与预算**：主代理指定单一集成者，逐片相对交接基线核对 diff（含新增、删除与未跟踪），不拾取用户或其他片改动，不操作共享 Git 索引；越界先停片调查，不自动覆盖或撤销。初次集成失败先取证；提交有新证据的候选修复才占一次尝试，返工同样适用。同根因跨片共用问题预算，不因换片、换写入者重置；复验不重复计次。独立片可继续，涉及共享契约或污染验证时先停相关片。full 账本记录片、写入者、状态与任务共用 `r/5`、`d/3`。
5. **真实证据**：记录实际并发证据（分派事件或开始/结束时间区间，须证明执行重叠），以及判断依据 + 风险与隔离方式。串行包装不得称并行；计划同时分派或多个角色不等于实际并发。没有真实重叠时如实报告串行；未做收益测量不得宣称提速。
