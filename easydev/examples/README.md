# 模型配置示例

[models.cross-provider.json](models.cross-provider.json) 是角色配置示例，演示跨供应商写法（开发与审查分属不同供应商，`upgrades` 再对调）；内置默认则是三个角色都 `inherit`、`upgrades` 为空。可按宿主支持的模型与深度替换示例值，文件名沿用历史名称，示例中的 ID 是当时环境的取值，不构成供应商推荐。

示例不会自动加载；复制到选定位置或在对话中明确指定。来源优先级、字段和模型升级只以 [模型配置](../references/models.md) 为准。能力说明不作为虚构模型 ID，实际值须核对宿主工具；不修改密钥或宿主配置。
