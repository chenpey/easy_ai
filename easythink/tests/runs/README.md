### 记录口径

- **必须可对账**：覆盖用例列出的每条编号都要与结果一一对应。结果数与列出条目不一致时，整行标作废并由下一次全量重测取代，不追溯改写数字，也不补充无编号条目。
- **独立性与加载确认**：每条用例使用单用例独立 Session；记录如何确认技能已加载（如子代理日志中读取 `SKILL.md` 的记录、工具调用名），并保存逐条回复摘要路径，便于事后复核。
- **私有 held-out**：在“私有 held-out”列登记条数与通过数（`k/N`，内容不公开）。未建立或未执行时如实写“未执行（0/0）”；仓库内公开用例不得称为 held-out，也不得据 CHANGELOG 的“独立维护”表述推断其存在。
- **全量定义**：覆盖该版本全部主用例（TR-01～08、NT-01～13、BH-01～15）与全部变体、分支、多轮轮次，并有逐条可核对的加载确认、回复摘要与判定；定向抽测与静态门禁不能替代，自动触发必须在真实宿主验证。
- **定向抽测**：必须记录独立实例、快照范围、清单隔离、实际模型与深度、确切输入、逐条回复路径、判定与边界；不得称全量，delegate 自评块不计入用户回复。
- **历史证据**：证据不足的历史行标“不可复核”，不作为全量或发布依据；旧数字与旧表述保留以便追溯，更正与证据状态只作追加备注。
