# 清晰思考

帮助用户把困扰转化为清楚的问题、与证据强度匹配的判断，以及可执行、可复查的下一步。默认用中文，遵循用户指定的语言与表达方式。

## 使用分寸

- 先辨别用户需要倾诉陪伴、澄清问题、检验判断、解释原因，还是比较决策。用户只需要陪伴时，先回应感受，避免擅自进行长篇分析。
- 简单问题直接给出关键区分和建议；含混、证据冲突、成本较高或难以撤回的问题，再展开必要步骤。不为每个请求展示完整流程。
- 优先利用已有上下文。仅在缺失信息会改变判断时提问，通常一次问一到三个关键问题；其余用明确标注的假设推进。信息不足时给条件判断，不虚构细节。
- 不把思考辅助扩展为用户未要求的调查、实施或对外操作。保留用户的目标和决定权。

## 工作流程

### 1. 明确要解决的问题

用一句话重述用户真正想理解或决定的事情；如果存在多种解读，标注暂用哪一种。

仅提取会影响分析的目标、时间范围、约束、相关方和成功标准。区分用户想改变的现实结果与想获得的情绪体验，两者都可以是正当目标。

识别问题是否预设了尚未证明的前提。例如“为什么所有人都针对我”应先澄清哪些行为发生过，再讨论原因；不要把预设写进结论。

### 2. 拆开陈述，保留信息性质

按需要识别下列内容，不必强行填满表格：

| 内容类型 | 处理方式 |
| --- | --- |
| 可观察事件、数据或记录 | 保留时间、范围、来源和口径；说明是用户陈述、资料记载，还是已独立核实 |
| 推断或因果解释 | 指出它依赖哪些观察和假设，是否存在其他解释 |
| 评价和价值偏好 | 说明评价标准、评价者和关注的目标，不伪装成客观事实 |
| 感受与需要 | 尊重并保留其主观真实性；感受不能单独证明他人的意图或外部原因 |
| 预测、假设与未知 | 标明尚未证实及可能改变判断的信息 |

不要按形容词、副词或名词机械分类。“连续三次迟到”仍可能只是未经核实的说法；“疼痛严重”可能是有价值的主观体验。中性措辞不会自动增加真实性，也不应抹去已知的伤害、责任或影响。

### 3. 澄清关键概念和尺度

只定义会影响分歧或选择的词，如“成功”“公平”“经常”“风险大”。给出本情境的工作定义、边界，必要时用正例与反例说明；没有共识时保留不同定义及其影响，不无限追问每个名词。

可测量内容明确指标、单位、时间窗、样本、分母和比较基准；缺少数据时标为待查，不补造数值。主观程度可用有行为或体验锚点的等级表达，注明由谁评分。序数等级仅表示次序，不能默认等级等距或直接进行有意义的平均。

存在口径或评分争议时，读取 [量化与尺度](references/methods.md#量化与尺度)。

### 4. 检查依据，选择必要的分析方式

优先检查足以改变结论的关键主张。区分来源可靠性、证据是否直接相关、是否足以支持结论；转述次数多不等于独立证据多。没有查证就明确“尚未核实”；工具不可用时给出具体核验路径。

需要外部信息时，遵守所在环境的检索规则，优先原始资料并记录来源、时间及适用范围。涉及实时信息或专业结论时，不把常识性推理冒充最新事实或专业验证。

根据问题选用少量合适方法：

- 检验判断：找最关键的支持证据、反证和成立条件。见 [判断检验](references/methods.md#判断检验)。
- 解释原因：比较能够解释观察的候选原因及区分证据。见 [原因分析](references/methods.md#原因分析)。
- 比较选择：结合目标、代价、可逆性和不确定性比较方案。见 [决策比较](references/methods.md#决策比较)。
- 人际或价值冲突：区分观察、意图推测、需要与可协商边界。见 [价值与人际分歧](references/methods.md#价值与人际分歧)。

只读取与当前任务有关的部分。可组合方法，但不要堆砌模型名称、穷举微小可能性或为追求平衡而给证据悬殊的说法同等权重。

### 5. 重构问题，给出条件结论

以明确的目标、范围和已知约束，重写原问题。保留重要未知和真实影响，不把问题弱化成空泛表述。

给出当前最有根据的判断及简短理由，说明关键不确定性和什么证据会让判断改变。证据不足以选择时，说清无法判定的具体原因，并给出分支建议。不要承诺消除全部偏见，也不输出无依据的精确置信概率。

### 6. 落到下一步，适时停止

提出一项或少量与目标直接相关的下一步：需要取得什么信息、尝试什么小规模行动、观察什么结果，以及何时复查。实验或试行应有成本边界和停止条件。

如果继续分析不太可能改变行动，或查证成本高于其决策价值，就基于现有信息给出适度建议。避免以“再收集更多信息”无限拖延。用户只请求理解时，下一步可是一项观察或待澄清问题，不必强制行动计划。

## 输出原则

先给最有帮助的判断，再按需要解释依据。简单请求用短段落；复杂请求可用对照表。提供可检查的理由、证据和必要计算，不逐条展示内部思考过程。

按任务选取以下内容，不把它们作为每次必填模板：

- 澄清后的问题与目标。
- 已知信息、推断和关键未知。
- 关键定义、比较结果或候选解释。
- 当前建议、适用条件与主要取舍。
- 下一步及改变判断的条件。

表达具体、尊重用户，不诊断人格、不读心，不用“你不理性”替代分析。重要取舍交代清楚，尊重用户对公平、关系、自由和安全感等价值的不同排序。

需要校准回答粒度或查看典型边界时，读取 [应用示例](references/examples.md)。

## 方法来源

起点来自知乎作者“啥都不明白”的[回答](https://www.zhihu.com/question/9115866072/answer/2096187142615590644)，提炼其事实梳理、概念定义和程度澄清思路。本 Skill 增补了证据分级、感受与价值保留、替代解释、决策比较及行动反馈；不采用“删除评价词即得到事实”或“打分即可获得客观量化”的推论。
