## 回复

`arr[len]` 越界，是因为 Python 的数组下标范围是 `0 ... len-1`，`len` 本身并不在范围内；由于它是最后一个元素的下一位，这一位并不属于数组。

- 想取最后一个元素：用 `arr[len - 1]`，或 `arr[-1]`
- 想判断循环边界：写成 `for i in range(len(arr))`，而不是 `range(len(arr) + 1)`
- 如果 `i` 会走到 `len`，问题通常在于上界计算多加了 1，或者把“元素个数”当成了“下标”

先看这个 `len` 是从哪来的：如果它等于元素个数，就减 1；如果它本来表示下标，则检查循环的终止条件是否写成了 `<=`。
