## 0.2.7 更新说明（2026-10-23）

本次发布修复 `BH-03`/`BH-01` 规约细节、补齐误触发负例、控制 `SKILL.md` 体量并移除与 `methods.md` 的重复规则，同时在独立子代理中完成首轮盲测回归记录。

- **修复高风险规则与 `BH-03` 轮次矛盾**：
  - `SKILL.md` 新增独立小节 `### 高风险与不可逆抉择`（与 `### 安全优先` 并列），明确“用户明确知情”须以具体确认或复述核心风险为准（而非仅用“我知道了”敷衍），并规定后续风险实质升级（如追加借贷、加杠杆、动用必需资金）时不受“不重复劝阻”限制；
  - `references/methods.md#决策比较` 删除重复的高风险长段描述，改为指向 `SKILL.md#高风险与不可逆抉择`，消除两处漂移风险；
  - `tests/behavior.md` 的 `BH-03` 轮次 2A 改为“改用自有闲置资金、无借贷且具体复述确认核心风险”，消除与轮次 1“借高利贷（可能波及家人）”的前提矛盾。
- **消除 `BH-01` 变体 B 编造热线风险**：`SKILL.md#安全优先` 与 `tests/behavior.md` 明确：面对自伤信号时先接住感受、温和确认当下安全、引导联系身边可信的人或当地紧急/专业援助；未知所在地区时不编造具体号码，改用“当地紧急服务/心理危机热线”表述或先询问所在地区。
- **补齐两类误触发负例**：`SKILL.md`（`description` 与诉求选择）及 `tests/behavior.md` 新增 `NT-10`（带情绪的明确执行任务，如“代码又崩了烦死了，帮我看这个报错”）与 `NT-11`（低风险日常琐碎选择，如“中午吃面还是吃米饭”），明确直接执行或给简短建议，不启动共情询问或决策矩阵。
- **控制 `SKILL.md` 运行时体量**：将外部检索细则与违法/侵权目标拒绝后的正当诉求分流细则下沉至 `references/methods.md`（`#判断检验` 与 `#价值与人际分歧`），`SKILL.md` 仅保留核心规则与指针，体积由 `10,985` 字节降至 `9,844` 字节，并在 `tests/behavior.md` 设立 `≤ 10 KB` 的体量上限。
- **加固手动安装脚本与排除非运行时文件**：
  - `README.md` 安装命令（新增 Windows PowerShell 版本）先在目标同目录的临时目录暂存并校验 `SKILL.md`，成功后再备份旧版并原子替换，避免复制失败时处于无可用版本状态，并在结束时打印备份路径、安装路径与版本；
  - 安装过程仅复制运行时所需的 `SKILL.md`、`references/` 与 `agents/`，排除 `tests/`、`CHANGELOG.md` 与 `README.md`；
  - 恢复 `CHANGELOG.md` 中 `0.2.5` 历史条目的原始表述，不做回溯改写。
- **完成首轮独立子代理盲测回归**：在未接触 `tests/behavior.md` 验收清单的隔离实例中实测 `NT-05`、`NT-06`、`NT-10`、`NT-11`、`BH-01(A/B/C)`、`BH-03(1/2A/2B)`、`BH-04(A/B)`、`BH-08(1/2)` 并登记结果。

## 0.2.6 更新说明（2026-10-23）

本次发布针对 0.2.5 的审计反馈修复手动安装脚本缺陷、恢复检索环境与隐私约束、细化倾诉与有议题消息的分流，并扩充行为回归规约。

- **修复 README 手动安装脚本缺陷**：手动安装命令改用子 shell + `set -euo pipefail` + `mktemp -d` + `trap` 清理，克隆成功后再备份旧目录（`~/easythinking.bak.<timestamp>`）并复制新文件，避免克隆失败时误删已安装版本或直接覆盖本地修改；专用目录同步命令同样增加源文件检查与旧版备份，并注明各 Agent 目录约定核对时间（截至 2026-10）。
- **恢复检索的环境限定并增加隐私约束**：`SKILL.md` 步骤 4 恢复“在所在环境允许且具备检索工具时，默认主动检索核实”，将硬编码的“一次”改为“通常一到三次，直到关键前提有可靠来源支持或确认查不到”，并增加隐私保护要求（检索词仅保留最少公开信息，不带入人名、个人隐私或未公开的内部信息）。`references/examples.md` 同步注明示例中的查证结果为假设示意。
- **拆开“无具体议题的倾诉”与“有议题但未明说请分析”**：`SKILL.md` 诉求选择明确“有具体议题（如纠结选项、怀疑判断、追问原因、人际摩擦）时默认按相应诉求直接处理，不必先反问是否需要分析”；仅在“倾诉陪伴，或情绪主导且无具体议题”且不确定意愿时才用一句话轻问。删除 `SKILL.md` 正文中的固定确认话术，仅保留在 `references/examples.md` 并注明“话术仅为示意，不必逐字复读”。
- **补充持续严重低落时的支持提示**：`SKILL.md#安全优先` 与 `references/examples.md` 补充：若流露出持续、严重的无力感、绝望或日常功能明显受损，温和了解持续时间与现实影响，并提示可向身边信任的人或专业人员寻求支持。
- **高风险提示补充“不说教”与后果归属区分**：`SKILL.md` 与 `references/methods.md#决策比较` 明确：先回应高风险决定背后的处境或压力；若后果主要由用户自己承担，同一风险充分交代一次后将决定权交还用户，用户明确知情后不再每轮重复劝阻；若波及他人权益或公共安全，则持续明确风险边界。
- **价值底线补充拒绝后的正向分流**：`SKILL.md` 输出原则明确：拒绝协助违法、恶意侵权或有害手段的同时，若背后存在正当诉求（如遭受不公、希望止损或维权），可协助梳理核心诉求与合法、安全的解决途径。
- **精简运行时 `SKILL.md`**：移除 `SKILL.md` 末尾不直接作用于模型行为的“方法来源与致谢”段落，仅保留在 `README.md` 中，降低每次触发的上下文占用。
- **扩充 `tests/behavior.md` 行为回归规约**：明确其为文字行为验收规约而非自动脚本，新增全局不报幕与不复读固定模板约束；扩充 5 条近邻负例（`NT-05` 至 `NT-09`）；扩展 `BH-01`、`BH-02`、`BH-03`、`BH-04`、`BH-05`、`BH-06`、`BH-08`、`BH-11` 与 `BH-12`，并新增回归执行记录表。

## 0.2.5 更新说明（2026-10-23）

本次发布重点吸收独立审计意见，修复规程边界盲区，精简上下文占用，并补齐工程文档与测试规约。

- **扩大触发面**：`SKILL.md` 的 `description` 补充“为什么会这样”“同事总针对我”“我是不是想多了”等高频人际困惑、因果归因与倾诉短语，并显式说明即使用户未明说“要分析”，只要涉及困惑、归因或纠纷均可触发辅助思考。
- **不可逆与高风险表态规则**：在“使用分寸”与 `methods.md#决策比较` 中明确“不可逆与高风险抉择”边界：面对可能导致重大不可逆损失、超出承受能力或触及安全底线的选择，必须明确指出核心担忧、最坏后果与结论成立的关键前提，不以“尊重决定权”为由回避风险提示；充分交代代价后再将决定权交还用户。
- **倾诉边界与安全置顶**：诉求表格第一行明确“倾诉陪伴或信号不明（没有明确求解）”的处理原则：先回应感受与处境，意图不明时用一句话温和确认是否需要梳理，不擅自转入长篇分析；同时在表格第一行显式置顶“若出现现实安全信号，以安全优先为准”，防止模型因“避免分析”而忽略危险干预。
- **价值排序的合规与安全边界**：在输出原则中明确：涉及违法犯罪、恶意侵害他人合法权益或现实人身危害的目标，不适用价值排序的尊重，转入一般安全与合规规范处理。
- **检索核实默认规则与去重**：在“步骤 4”集中收敛为默认核查规则：当环境提供检索工具且关键前提是可查证的外部事实时，默认主动检索核实一次并给出可靠来源、时间与适用范围，不把常识性推断冒充事实；只有在没有工具或无法查实时才给出核验路径；同时消除“使用分寸”中重复出现的检索表述。
- **步骤 3 精简瘦身**：将“步骤 3”第二段关于数据量化与主观等级的冗余说明精简，改为关键指针指向 `references/methods.md#量化与尺度`，减少每次触发的基础上下文开销。
- **分支建议防止和稀泥**：在“步骤 5”中明确：证据不足以判定时，分支建议须给出当前信息下的暂定倾向（若有），或明确指出能够打破僵局、改变选择走向的最小关键信息。
- **新增三类典型示例**：`references/examples.md` 补全信号不明的倾诉（演示先共情+轻问）、工具可用的外部事实检索核实（演示主动检索官方公告澄清事实后再分析）和多轮增量更新（演示显式交代“什么变了、为什么变”）。
- **工程与安装加固**：
  - `README.md` 增加确定性的手动安装与软链接对照命令，消除依赖 LLM 自主执行黑盒操作的不确定性；
  - 补回并完善“方法来源与致谢”（感谢知乎作者“啥都不明白”的最初启发）；
  - 新增 `tests/behavior.md` 行为回归规约（涵盖 Should-Trigger、Should-Not-Trigger 与行为检查清单）；
  - 新建本 `CHANGELOG.md` 记录版本演进。
